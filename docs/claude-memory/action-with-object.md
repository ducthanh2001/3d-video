Each vignette frame: a big figure (~0.84 scale), whole body in an effort pose (diagonal lean, bent knees), hands ON a big object
(as big as or bigger than him), the counter right next to the action; the payoff is visible WHILE he acts (pushing the boat
into the sea, hammer on the chisel as the statue emerges, leaning back on the kite string). Objects must be real and logical
(no magic transformations like paper plane → jet).

**Why:** the user rejected several "PROVE IT" frame sets (2026-11-08): magic transformations were "không hợp lí", and frames where
the figure just stands beside the result "chưa okie"; they asked for "mỗi cảnh phải có cảnh nhân vật hành động với đồ vật" like
the competitor (pushing boulders, digging, sledgehammer 99→100).
**How to apply:** check every new frame against this; example: src/episodes/prove/V5Frames.tsx; see [[competitor-visual-grammar]].
