When a film mixes human scenes with object-only scenes (competitor style: one labelled object on black):
- The object must prove the TITLE's idea, not a nearby idea. For "Pressure makes diamonds" it must show pressure TURNING something
  ordinary into something precious (coal → diamond, iron bar hammered → blade). "Pressure makes it go farther" (hose jet 5 m,
  spring launch, pumped tyre) was rejected: "áp lực phun xa 5m thì có ý nghĩa gì... bạn hiểu sai ý".
- B&W only: white/grey pictogram objects on black; gold = what it becomes, red = what is lost. Objects that need colour to be
  recognised (green olives, terracotta pots) fail ("không phù hợp với phong cách đen trắng").
- Real physics, no magic, nothing that is only a cartoon convention (rain melting a pot in seconds was "chưa hợp lí").
- It must feel clever, like the competitor's scales / funnel / tap "YOUR EFFORTS" (tyre and spring were "chưa thông minh").
- Alternate human / object / human; two object scenes in a ~32 s film is enough.

**Why:** the user rejected kiln pot, tyre, garden hose, olive press, spring before approving the coal press + the anvil (2026-11-12).
**How to apply:** before drawing an object scene, write one line "the object shows <title meaning> because..." and check it in grey.
